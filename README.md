# Комплаенс помощник
# Постановка задачи

> Проектная работа по дисциплине **«Прогнозно-аналитические системы»**  
> Профиль подготовки: **«Управление данными»**

---

## 1. Предметная область

**Санкционная активность и комплаенс-контроль.**

Область связана с мониторингом санкционных списков, которые ведут различные юрисдикции.
Санкционные списки **постоянно расширяются**, и для комплаенс-подразделений критически важно понимать динамику этого расширения — как в целом, так и в разрезе отдельных юрисдикций.

---

## 2. Прогнозируемый показатель

**Основной показатель:**

> Количество новых санкционных записей за период (неделя / месяц).

**Дополнительный показатель:**

> Кумулятивное количество активных санкционных записей на конец периода.

Показатель обладает выраженной **временной составляющей**, что позволяет строить прогнозные модели на основе исторических данных.

---

## 3. Практическая задача

Санкционные списки растут **неравномерно**: периоды затишья сменяются всплесками, связанными с политическими событиями, пакетами санкций и решениями регуляторов. Комплаенс-подразделения вынуждены реагировать **постфактум**, что создаёт операционную нагрузку и повышает риски.

Разрабатываемая система позволяет **заранее оценить ожидаемый прирост санкционных записей**, чтобы:

- **планировать нагрузку** на комплаенс-команду;
- **своевременно обновлять** процедуры скрининга;
- **оценивать риски** при проверке контрагентов.

---

## 4. Пользователь

Система ориентирована на следующие роли:

| Роль | Что получает от системы |
|---|---|
| **Аналитик комплаенса** | Прогноз прироста санкционных записей, дашборды с динамикой |
| **Руководитель группы операционного подразделения комплаенс** | Агрегированные показатели по юрисдикциям, план нагрузки |
| **Руководитель отдела операционного подразделения комплаенс** | Стратегическая картина санкционной активности, оценка рисков |

---

## 5. Источники данных

В проекте используются **разнородные источники данных** (не менее двух), различающиеся по способу получения и формату представления:

| № | Источник | Что предоставляет | Формат / доступ |
|---|---|---|---|
| 1 | **OpenSanctions** | Агрегированные санкционные списки (OFAC, EU, UN, UK и др.) | JSON / CSV, API, дельты |
| 2 | **Росфинмониторинг** | Национальный перечень террористов и экстремистов | CSV / парсинг открытых данных |
| 3 | **World Bank API** | Макроэкономические показатели (экзогенные признаки) | REST API (JSON) |

---

## 6. Ожидаемый результат

Функционирующий прототип прогнозно-аналитической системы, который:

1. автоматизированно собирает данные из нескольких источников;
2. хранит исходные и обработанные данные по слоям;
3. выполняет очистку, преобразование и контроль качества;
4. строит прогноз санкционной активности;
5. представляет результаты в виде интерактивных дашбордов.
